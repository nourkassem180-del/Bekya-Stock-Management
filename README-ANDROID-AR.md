# Bekya Stock Management - مشروع Android

هذا مشروع Android Studio يحوّل واجهة Bekya Stock Management الحالية إلى تطبيق Android باستخدام WebView، مع الاحتفاظ بملفات HTML/CSS/JavaScript كما هي.

## بناء ملف APK على الكمبيوتر

1. ثبّت Android Studio بإصدار حديث.
2. فك ضغط `BekyaStockAndroid.zip`.
3. افتح مجلد `BekyaStockAndroid` من Android Studio.
4. انتظر اكتمال Gradle Sync وثبّت Android SDK Platform 35 إذا طلبه البرنامج.
5. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. بعد انتهاء البناء اختر **locate**. غالباً ستجد الملف في:
   `app/build/outputs/apk/debug/app-debug.apk`
7. انقل APK إلى هاتف Android، وافتحه، واسمح بالتثبيت من هذا المصدر عند طلب ذلك.

## ملاحظات مهمة

- هذا مشروع قابل للبناء في Android Studio، وليس ملف APK مبنياً مسبقاً.
- التطبيق يحتفظ بالبيانات محلياً داخل WebView على نفس الهاتف.
- لا توجد مزامنة بين الهاتف والكمبيوتر أو بين عدة مستخدمين.
- اختيار المدير/أمين المخزن في النسخة الحالية تجريبي وليس حماية صلاحيات فعلية.
- بيانات النسخة الحالية التجريبية ستظهر عند أول تشغيل، ويمكن حذف بيانات التطبيق لإعادة البداية.
- قبل استخدامه في مخزون فعلي، يلزم تطوير خادم مركزي وقاعدة بيانات وصلاحيات ومراجعة حركات المخزون والفواتير.
