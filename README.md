# Bekya Stock Management — نسخة البداية

هذه نسخة أولية قابلة للتشغيل كـ PWA على الهاتف والكمبيوتر. الواجهة متجاوبة، وتخزن بياناتها محلياً في المتصفح، ويمكن تثبيتها من المتصفح بعد تشغيلها عبر HTTPS أو localhost.

## التشغيل السريع على الكمبيوتر
1. ثبّت Node.js (الإصدار LTS).
2. فك ضغط المشروع.
3. افتح الطرفية داخل مجلد المشروع.
4. نفّذ:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:4173`.

## التشغيل على الهاتف
- ارفع المجلد إلى استضافة HTTPS، أو شغّل خادماً على شبكة محلية بحيث يكون الهاتف والكمبيوتر على نفس الشبكة.
- افتح رابط التطبيق من Chrome على Android.
- من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
- للتثبيت المحلي على الهاتف يلزم عنوان HTTPS أو localhost؛ فتح index.html مباشرة لا يفعّل كل خصائص PWA.

## ما يعمل في هذه النسخة
- تسجيل أجهزة مع باركود نصي فريد.
- تسجيل نواتج التفكيك وربطها بباركود الجهاز.
- عرض رصيد الأصناف بحسب المخزن والوحدة.
- طلب تحويل وموافقة تجريبية من مدير النظام.
- تسجيل فواتير مبدئية وخصم الكميات المسجلة من الرصيد.
- حفظ محلي في المتصفح، وتشغيل واجهة أساسية دون اتصال بعد أول تحميل.
- تنزيل نسخة احتياطية JSON.

## بيانات التجربة
توجد بيانات تجريبية أولية لجهاز ونواتج تفكيكه. يمكنك حذف بيانات الموقع من إعدادات المتصفح لإعادة التهيئة.

## حدود مهمة قبل الاستخدام الفعلي
هذه ليست النسخة الإنتاجية متعددة المستخدمين:
- لا يوجد خادم مركزي أو PostgreSQL حتى الآن.
- اختيار «مدير/أمين مخزن» توضيحي فقط وليس نظام صلاحيات آمن.
- لا توجد مزامنة بين الأجهزة؛ البيانات محفوظة في متصفح كل جهاز.
- موافقة التحويل محاكاة محلية، ولا يوجد سير عمل اعتماد على الخادم.
- الفواتير مبدئية؛ لا يوجد ترقيم قانوني أو ضريبة أو PDF أو مرتجعات أو تحصيلات.
- لا يوجد مسح بالكاميرا حتى الآن؛ أدخل رقم الباركود يدوياً أو استخدم قارئ باركود USB/Bluetooth.
- يجب عدم استخدام هذه النسخة لإدارة أرصدة مالية أو مخزون حقيقي قبل بناء الخادم، المصادقة، صلاحيات قاعدة البيانات، النسخ الاحتياطي، واختبارات الجرد والتزامن.

## الخطوات التالية للإنتاج
1. Backend مركزي (NestJS) وPostgreSQL.
2. مصادقة حقيقية وصلاحيات على مستوى API وقاعدة البيانات.
3. مخازن ومحافظات فعلية وإسناد الموظفين.
4. حركات مخزون غير قابلة للمحو مع قيود ذرية تمنع الرصيد السالب والتكرار.
5. تحويلات باعتماد المدير وتأكيد استلام.
6. فواتير مع ترقيم وضرائب وإيصالات ومرتجعات.
7. مزامنة offline-first مع معرف فريد لكل عملية وحل التعارضات.
8. اختبار أمان ونسخ احتياطي ونشر HTTPS.
